Plugin para exibir a landing page institucional da ACEJUVI via shortcode.

== Installation ==

1. Envie a pasta `acejuvi-shortcode-plugin` para `/wp-content/plugins/` ou instale o arquivo ZIP pelo painel do WordPress.
2. Ative o plugin "ACEJUVI Landing Page Shortcode".
3. Crie ou edite uma pagina.
4. Insira o shortcode `[acejuvi_site]`.

== Shortcodes ==

`[acejuvi_site]`

Exibe a landing page ACEJUVI.

`[acejuvi_site height="1200"]`

Define uma altura inicial. Depois do carregamento, a altura se ajusta automaticamente ao conteudo real.

`[acejuvi_landing]`

Alias do shortcode principal.

== Notes ==

A landing page usa recursos externos ja presentes no HTML original, incluindo Tailwind CDN, Google Fonts e imagens hospedadas remotamente.
